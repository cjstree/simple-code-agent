# 本地工具与 MCP

Agent 默认提供本地读取、搜索、编辑、写入和 shell 工具。每次调用会修改文件或执行
shell 命令的工具时，Agent 都会请求批准。

本地读取工具为文本标注行号。`offset` 从 1 开始，可选 `limit` 指定读取行数。为了限制
模型上下文占用，每次结果最多返回 2,000 行或 50 KiB；如果还有内容，会给出下一次读取
使用的 `offset`。

本地 shell 工具分块读取输出，允许命令输出任意长度的行。最多保留 10 KiB 输出；超过
上限时等量保留开头和结尾，并在中间用标明省略字节数的截断标记连接。

MCP 集成是可选的。在 `.env` 中将 `MCP_URL` 设置为任意 Streamable HTTP MCP 端点，
例如 `http://127.0.0.1:8000/mcp`，Agent 会发现并添加远程工具。未设置 `MCP_URL` 时，
Agent 运行不依赖父级 RAG 后端。
